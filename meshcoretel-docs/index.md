# Heltec V4 Web Monitor

Этот репозиторий содержит расширенную прошивку MeshCore-репитера для высокомощной Heltec WiFi LoRa 32 V4/V4.3. Основные дополнения:

- Wi-Fi и MQTT с поддержкой MeshCoreTel;
- локальная веб-панель настройки;
- монитор RX/TX-пакетов и карта найденных узлов;
- выбор координат на карте;
- управление выходной мощностью в пределах аппаратных возможностей платы;
- обновление прошивки через веб-интерфейс.

Код основан на [VBart/MeshCoreTel-firmware](https://github.com/VBart/MeshCoreTel-firmware) и сохраняет совместимость с его release- и build-механизмами.

Если вам нужно просто выбрать устройство или скачать прошивку, начните с:

- [Сравнение устройств](./boards.md)
- [Загрузка и прошивка релизов](./releases.md)
